Remote Connection Manager

## 功能
1.一键清理 Windows 远程桌面（mstsc）残留痕迹。
2.自动扫描 7 类 RDP 痕迹：MRU 历史、服务器缓存、.rdp 文件、TERMSRV/* 凭据、VPN 拨号、设备重定向、非标准残留
3.精简视图：同地址合并为一行，对应 mstsc 下拉框选项，区分端口
4.勾选即删，缓存/凭据/残留联动清理
## 使用方法

1. 下载 `rdp_manager.exe`
2. 双击运行
3. 按界面提示操作即可
4.删除前自动备份（.reg 可还原，.rdp 移入备份目录）
5.操作前二次确认，无静默删除
6.单文件 exe，免安装
